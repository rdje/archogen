## Goal

Implement the typed, composable, implementation-free description foundation: S-expression
reading with source spans, namespaced imports, schemas, parameters, unit checking, functional
kind registration, and typed requirement normalization — enough language to express the
initial system completely at the feature/functionality level.

## Non-Goals

- No universal optimizer, no hundreds of device models (`ROADMAP.md` §12 M1 gate discipline).
- No implementation content in eADL: no algorithms, no code providers, no model bodies.
- No resolution or generation. Those are `M3` and `M4`.

## Acceptance Criteria (roadmap exit gate, §12 M1)

- Examples parse, type-check, and round-trip semantically.
- Importing and instantiating sub-HW and sub-OS modules works, including double instantiation
  without shared mutable elaboration state.
- Invalid examples produce source-localized diagnostics.
- At least twenty semantic examples exist: positive matches, relevant missing facts,
  conflicts, and unsupported cases.
- S0's executable-generation evidence is available before M1 is promoted as M3-ready.
