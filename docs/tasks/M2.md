# M2: one complete engine realization and its controls

## Metadata

- Tree ID: `M2`
- Status: `active`
- Roadmap lane: `ROADMAP.md` §12 M2; §7; §8; §9; §18 work packages 7, 8, 9; fixtures F17, F18, F29

- Owner: repo-local workflow

## Goal

Build one end-to-end engine catalog slice — fixed-priority scheduling behavior, task
lifecycle, timer management, interrupt dispatch, static allocation and layout — together with
the independent controls that make its claims meaningful: a separate reference model, a
scheduling checker with explicit applicability conditions, the cost-accounting contract, and
the first trust-dependency inventory.

## Non-Goals

- No joint resolver (that is `M3`) and no complete generated system (that is `M4`).
- The architecture spike is a falsification control; it must not become a second production
  kernel or dictate eADL's feature categories.
- No timing claim for any board merely because the checker works on abstract fixtures.

## Acceptance Criteria (roadmap exit gate, §12 M2)

- One catalog slice carries functional requirements, internal contracts, implementation,
  an independent reference, analysis applicability, and tests.
- Deliberate scheduler and timer errors are detected.
- The target spike has produced evidence or a named blocker.
- F18, F29 and the F17 refusal behavior pass.
