# M4: generate a complete system and the playground simulator

## Metadata

- Tree ID: `M4`
- Status: `pending`
- Roadmap lane: `ROADMAP.md` §12 M4; §6; §10; §18 work package 11; fixtures F13–F16, F19–F22, F26, F30
- Created: `2026-09-13`
- Owner: repo-local workflow

## Goal

Emit and assemble the complete generated system — Rust runtime, target bindings, static
tables, memory and linker inputs, startup substrate, build metadata, source provenance — plus
the hosted simulator composed from engine-owned models, and run both the hosted playground and
the QEMU target binary with recorded conformance evidence.

## Non-Goals

- No newly synthesized full CPU emulator (§6.3): the first generated simulator is device
  models plus a deterministic event harness over the shared runtime logic.
- No board claim. That is `M5`.
- No model implementation added to eADL.

## Acceptance Criteria (roadmap exit gate, §12 M4)

- The first described three-task system builds from a clean checkout with no edits to output.
- Hosted and emulator runs provide recorded conformance evidence.
- Linked memory accounting matches the plan.
- Missing relevant timing evidence appears in the report.
- The package includes the build-bound trust inventory and reviewed baseline status.
- S0's retained functional fixtures run through the supported path.
- Repeated generation produces identical canonical plans and generated sources.
