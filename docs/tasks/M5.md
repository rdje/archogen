## Goal

Generate for the selected physical board using the same OS functionality profile, run the
generated output without manual patches, and compare hardware observations against permitted
model behavior — analyzing discrepancies rather than editing the requirement to match a faulty
implementation.

## Non-Goals

- No timing claim beyond what the recorded measurement procedure supports.
- No substitution of QEMU for hardware. A virtual platform is not a board.

## Acceptance Criteria (roadmap exit gate, §12 M5)

- Generated output runs on the named physical board without manual patches.
- The evidence report identifies functional coverage and timing assumptions precisely.
- Any target-incompatible model has been corrected and its affected evidence invalidated.
- A failed boot is a failed exit gate even when its cause is understood.
