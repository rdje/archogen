## Goal

Produce a reproducible release package for the supported profile and targets, with complete
examples, command documentation, source and assumption provenance, known limitations, pinned
dependencies, and regression evidence — and with report statuses that cannot overstate what
was established.

## Non-Goals

- No claim of an end-to-end formally verified OS. The first release may accurately provide
  conditional timing analysis and tested runtime conformance, and must list the unproved links.
- No board support claim without `M5` evidence.

## Acceptance Criteria (roadmap exit gate, §12 M7 and §20)

- All applicable mandatory gates in §13 pass.
- The physical target is evidenced.
- The supported task and interrupt model is explicit.
- Report statuses cannot overstate evidence.
- Source and binary reproduction have been checked in the pinned environment.
- No unresolved correctness issue is hidden by a test waiver.
- A user can describe a supported HW+OS system, supply build inputs, and obtain a runnable
  generated system and simulator with a reproducible build and an accurate report.
