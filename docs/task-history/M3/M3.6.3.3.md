    one.

    inventory's host: `trust-new-shared`, `trust-shared-changed` naming the aspects, "no longer shared", or
    "unchanged"; otherwise "not compared" and why. The standing list holds every shared item, root form,
    classification and admission, none accepted before `M3.6.5`, and every `trust-unclassified-program` the
    inventory reports — there, not in the change part, so a classification that grew does not make every later
    commit's change part non-empty.

    report naming them. A root form or classification naming a package the commit no longer has, or a root whose
    target is gone, is refused by the inventory as `trust-baseline-stale` wherever it runs, since no inventory can be
    built without it; until now it was an error, exit 2.
