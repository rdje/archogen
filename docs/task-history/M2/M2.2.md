  ### What remains shared, disclosed because the acceptance demands it

  §4.4 requires shared logic between an implementation and its checker to be declared rather than
  eliminated. Four things are shared and each could produce a common error:

  | Shared input | Consequence |
  | --- | --- |
  | the contract text (`ROADMAP.md` §3.1, §8, §8.1) | a misreading the *contract invites* would be made by both |
  | `decision_priority-comparison-direction.md` | the priority direction is common to both |
  | the same model family produced both | §14: "a second model agreeing with the first is not ground truth" |
  | the adapter, written by `rt-core`'s author | a mapping error there can mask or manufacture a divergence |

  ⚠️ One incidental leak, disclosed by the reference's author unprompted: a `grep` for the
  repository's crate-attribute convention matched and printed one line of `rt-core/src/lib.rs` —
  `#![cfg_attr(not(test), no_std)]`. That is the exact pattern the brief already prescribed, and
  no type, signature or behaviour was exposed. Recorded rather than waved away, because a
  disclosure that only covers convenient cases is not a disclosure.
