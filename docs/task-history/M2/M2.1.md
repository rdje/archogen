  ### Acceptance Checklist (enforced by `TASK-ACCEPTANCE`)

  - [x] **ROOT CAUSE (WHY + WHERE)** — there was no runtime at all. Measured at the parent commit:
    `git ls-tree --name-only HEAD crates/` listed five crates with no `rt-core`, though §4.2 names
    it, and `git grep -lE 'TaskState|ready structure' HEAD -- crates/` printed nothing, `rc=1`.
    WHERE the gap bites next: `M2.2` is an **independent** reference model of these semantics, and
    §12 M2 warns that "a checker sharing the same erroneous recurrence with its reference does not
    qualify as independent" — so the semantics had to exist, and be written against the roadmap's
    words rather than invented, before a reference could be independent *of* anything.
  - [x] **ADDRESSED (verified)** — `cargo test -p rt-core` → `3 passed` (unit) and `14 passed`
    (the lifecycle suite), `0 failed`. Every §8 mechanism the leaf names is exercised on the host
    with no target: dispatch-from-idle distinguished from a switch, higher-priority preemption
    with the preempted job returning to `Ready`, resumption after completion, nested masking with
    latched delivery in priority order, overrun on a release before completion **and** on a second
    latched release, both overrun policies, and the fault path's trustworthy/not-trustworthy
    split.
  - [x] **NO REGRESSION** — `make focused` → `tier focused: passed`; `cargo test --all` → **374**
    passed, `0 failed` (357 before this leaf, `+17`); `scripts/check_doctrines.sh` →
    `=== all doctrines green ===`; `mdbook build docs/book` → `INFO HTML book written to`;
    `scripts/check_book_anchors.sh` → `OK (19 chapter(s))`. The leaf adds a crate, a book chapter
    and one tier step, and changes no existing behavior.
  - [x] **FIX** — `crates/rt-core/`, `no_std` outside its own tests. ⭐ **It decides and does not
    act**: every operation returns a `Decision`, and performing a switch belongs to the
    architecture port. That is §8's "separate policy state transitions from the execution
    substrate", and it is what makes the policy testable on a host — `M2.1`'s acceptance — while
    keeping a scheduling bug and a context-save bug from being the same bug. The task set is a
    fixed-capacity array sized by a const parameter: no heap, no `Vec`, no trait object, no
    allocation. A test asserts the scheduler's size is a function of the task count alone, so a
    pointer indirection would fail it.
  - [x] **REPRODUCE / ISSUE** — the `no_std` claim is **verified, not asserted**: adding
    `pub fn red_arm() -> String { String::new() }` outside `cfg(test)` →
    `error[E0425]: cannot find type \`String\` in this scope`, restored and rebuilt clean. ⚠️ What
    that shows is that the core *can* run without `std`, **not** that it builds for a bare-metal
    target — so a `no-std-build` step was added to the integration tier, requiring
    `riscv64imac-unknown-none-elf`, and it reports
    `UNAVAILABLE — the \`riscv64imac-unknown-none-elf\` target is not installed` rather than
    letting the stronger claim pass unexamined. Clippy caught a real design smell on the way:
    `Scheduler::next` shadowed `Iterator::next`, and the method is now `decide`, which also says
    what the crate does.
  - [x] **LOCKSTEP** — `docs/book/src/runtime.md` (new chapter) + `SUMMARY.md`; `xtask/src/main.rs`
    gains the bare-metal compile step and learns that a rustup **target** is not a program on
    `PATH`; `knowledge-map/subsystems.md`; `MEMORY.md`; `LIVE_STATUS.md`; `CHANGELOG.md`;
    `docs/TASK_TREE.md`.

  ### What `M2.2` must not do

  §12 M2: *"A checker sharing the same erroneous recurrence with its reference does not qualify as
  independent."* The lifecycle tests here are deliberately written against `ROADMAP.md` §3.1 and
  §8 — the contract — rather than against this implementation's shape, so they are a specification
  both implementations must satisfy. `M2.2`'s reference model must be derived from that contract
  and **not** from `crates/rt-core`'s code; if it is written by reading this crate, it will agree
  with it about anything this crate is wrong about, and the agreement will look like evidence.
