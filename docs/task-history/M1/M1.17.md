  ### A defect in the check itself, found by running it

  The first version of the self-test re-executed the script through `$0` against a temporary
  fixture. It **hung**, and a bounded trace showed why: the recursion's guard compared the base
  directory against a literal, which held for the parent and not the child, so the fixture arm
  and the real arm could interleave. Rewriting the doctrine as a `scan()` function called
  directly — no re-execution at all — removed the recursion rather than guarding it. ⚠️ Worth
  recording because the failure was in the *test of the check*, which is the one place a green
  result is least likely to be questioned.

  ### What this establishes, and what it does not

  It establishes that a single bug directory is a **deliverable**: complete, closed, portable and
  registered, verified by a gate with six demonstrated RED arms. It does **not** establish that
  any reproducer still reproduces — that is what each issue's exit-code contract carries, and it
  is re-measured by running them, as this leaf did (`7 pass / 0 fail`).
