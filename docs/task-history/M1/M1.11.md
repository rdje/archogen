  - [x] **ADDRESSED (verified)** — `docs/semantics/grammar.md` states the lexical and phrase
    structure as productions, and `crates/eadl-front/tests/conformance.rs` derives a recognizer
    from that file and checks four properties:
    `cargo test -p eadl-front --test conformance` → `6 passed; 0 failed`. Both accept all **62**
    corpus descriptions; both reject six malformed inputs; both produce the **same token spans**
    on every corpus file; and both accept **23 probes**, one per production.
  - [x] **NO REGRESSION** — `cargo fmt --all -- --check` → `fmt rc=0`;
    `cargo clippy --all-targets --all-features -- -D warnings` → no warnings; `cargo test --all`
    → **421** passed, `0 failed` (415 before this leaf, `+6`); `scripts/check_doctrines.sh` →
    `=== all doctrines green ===`. `reader.rs` is unchanged — `git diff --stat HEAD --
    crates/eadl-front/src` is empty. The grammar documents the reader's existing language; it did
    not require changing it, which is itself a result.
  - [x] **FIX** — the grammar document is the source, and the test *reads it*: one definition,
    not two. The EBNF dialect implemented is exactly the one the document's notation table
    describes, so a notation that can express more than the recognizer checks cannot creep in.
  - [x] **REPRODUCE / ISSUE** — ⛔ **three defects were found by red-arming this leaf's own
    mechanism, and the second changed what the leaf delivers.**
    (1) Splitting productions on `;` cut the `comment` rule in half, because `;` is also a literal
    *in* the language being described — caught by the tests' first run.
    (2) The recognizer returned one end position per expression and so could not backtrack out of
    an alternative: for `atom = ( string | number | symbol ) , ? delimiter` on `10ms`, `number`
    matched `10`, the lookahead failed, and `symbol` was never tried. It gave the right verdict
    for the wrong reason, and the red arm that weakened `symbol_start` **did not fire** — which is
    how it was found. Rewritten continuation-passing; the same red arm now fails with
    `grammar ACCEPTS / reader rejects` on `(period 10ms)` and `(counter-width 32bit)`.
    (3) ⭐ **Acceptance agreement turned out to be too weak a conformance claim.** Dropping `_`
    from hexadecimal literals in the reader left every test green while `(base 0x1000_0000)`
    silently became the two forms `4096` and `_0000` — verified by printing the canonical form:
    `(region device.timer (base 4096 _0000))` against the correct
    `(region device.timer (base 268435456))`. A memory-mapped base address of `0x10000000` read as
    `4096`, with both implementations "accepting" the file. Token **segmentation** is now compared,
    and that mutation fails naming the byte offsets:
    `examples/periodic-three/system.eadl: 127 tokens vs 128 — grammar sees "0x1000_0000" at
    953..964, reader sees "0x1000" at 953..959`.
    A fourth finding needed no mutation: **the corpus is not a conformance suite.** It contains
    exactly one number with a digit separator and that one is hexadecimal, so nothing in it
    reached decimal separators, signs, escapes or CRLF. The 23 probes exist for that reason.
  - [x] **LOCKSTEP** — `docs/book/src/reading.md` points at the normative grammar;

  ### Lesson promotion

  `a parser is not a specification, and "both accept it" is not conformance` →
  `promotion: declined (this leaf is three already-recorded lessons applied to a language — a grammar existing only as prose is docs/knowledge/prose-beside-data-goes-unenforced.md, a suite blind to a class of error is docs/knowledge/a-gate-is-only-as-sharp-as-its-fixtures.md, and a red arm that fails to fire is docs/knowledge/verify-the-mutation-applied.md; a fourth entry answering the same three questions makes the retrievable layer harder to search, not easier)`

  ### What this establishes, and what it does not

  It establishes that the normative grammar and the reader accept the same language **and agree on
  where every token begins and ends**. It does not establish that the reader builds the right tree
  from those tokens, nor that it assigns the right value to each — a reader that tokenized
  identically and mis-nested, or read `1.5` as three halves, would pass. Nesting is the corpus
  suites' business; value exactness belongs to `M1.12`, which is why the reference is a separate
  leaf rather than a section of the grammar.
