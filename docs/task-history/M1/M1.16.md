  ### Acceptance Checklist (enforced by `TASK-ACCEPTANCE`)

  - [x] **ROOT CAUSE (WHY + WHERE)** — `M1.15` gave each bug an ID and a state but left the
    materials pooled: one `repro/` and one `evidence/probes/` served all seven, so acting on
    `LS-003` meant running a script named for `LS-002` over a corpus of twelve files, ten of
    which were irrelevant to it. WHERE: the coupling was in the layout, and it had a measurable
    consequence — a single shared `EXPECTED.txt` meant **any** upstream fix changed the frozen
    file for every issue at once, so no issue could be moved to `verified` independently of the
    rest. There was also no register: the status board lived inside prose, and nothing recorded
    totals, so "what is still open" could not be answered without reading seven files.
  - [x] **ADDRESSED (verified)** — seven self-contained sub-trees under `issues/<ID>-<slug>/`,
    each holding its own `README.md`, its own `repro.sh` and its own `evidence/`. Each reproducer
    reports its verdict as an exit code (`0` reproduces, `3` changed — possibly fixed, `2` could
    not run). All seven were executed after the split: `reproducers: 7 pass / 0 fail`, including
    two written for this leaf — `LS-004` now proves its three symptoms independently
    (`failed cargo invocations in log … 2`, `'seeded.' messages printed … 1`,
    `files actually in generated/ … 0`) rather than being a side-observation of `LS-001`, and
    `LS-005` checks the guide's section order mechanically (`'Add and pin' … line 17`,
    `'Initial PGEN preparation' … line 89`, `forward references … 0`). `INDEX.md` is the
    per-vendor register — every bug, state, severity, opened and last-verified date, plus totals
    by state and by severity — and `docs/feedback/README.md` is the cross-vendor index above it.
  - [x] **NO REGRESSION** — no archogen crate, manifest or test touched; `git diff --cached
    --stat` reports 41 files, all under `docs/feedback/` plus `.gitignore`. A link census over
    the layer reports `broken links: 0`; `bash -n` parses all seven reproducers; every `repro.sh`
    is mode `-rwxr-xr-x`; no frozen observation contains a checkout-specific path (a census
    over the three absolute home/volume prefixes DOCPATH names → no match). `bash scripts/check_doctrines.sh` →

  ### What this establishes, and what it does not

  It establishes that the tracker is **usable by its recipient**, not only by its author: one bug
  can be reproduced, fixed and re-verified without touching another's directory, and the register
  answers "what is still open" in one table. It does **not** add or change a finding — all seven
  measurements are `M1.14`'s, re-executed unchanged. Two blockers remain open upstream, and
  archogen's own question — whether an external engine can be an independent recognizer — stays
  open behind `LS-002`.
