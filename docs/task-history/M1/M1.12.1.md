- ID: `M1.12.1`
  Status: `done`
  Goal: the language reference exists and its **value table is executed**. Write
  `docs/semantics/reference.md` with normative chapters for number exactness, strings and escapes, and
  canonical form, each carrying a table of `literal → exact value → canonical text`; and write
  `crates/eadl-front/tests/reference.rs`, which reads those tables **out of the document** and runs
  every row against `crates/eadl-front/src/reader.rs` and `form.rs`. This is the leg `M1.11` named by
  name and could not close: token segmentation is compared there, value is not.
  Acceptance: a row the reader disagrees with fails naming the literal, the expected value and the
  actual one; F-B, F-D and F-E are fixed with a measured before→after each, and the fix is what makes
  their rows pass rather than the rows being written to match the reader; the mechanism has RED arms
  for a wrong value, a wrong canonical text, a row deleted from the table, and a table the document
  stops carrying; no measured figure appears in the reference; `make focused` exit `0`.
  Verification: see the acceptance checklist below.
  Commit: `ARCHOGEN-M1-0072 (leaf M1.12.1)`

  ⛔ **The expected values must be derived, not transcribed.** A table filled in by printing what the
  reader produced is a transcription of the implementation and is as unfalsifiable as no table at all —
  the exact defect `M1.11` existed to end. Each row's value comes from the literal's arithmetic meaning
  (`0x1000_0000` = 16^7 = 268435456, computed independently of the reader), from §7.4's exactness
  requirement, or from this tree's recorded decisions; a row where that derivation and the reader
  disagree is a **finding**, and F-B/F-D/F-E are three such rows.
